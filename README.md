# Mundo da Mulher – E-commerce Front-end

Projeto front-end de um e-commerce fictício de moda feminina, desenvolvido com foco em estruturação de layout, organização visual e fundamentos de desenvolvimento web.

## Demo

Projeto publicado utilizando GitHub Pages:

https://thiagorod-48.github.io/Constru-o-em-site-de-vendas/

## Objetivo do projeto

Este projeto foi um dos primeiros desenvolvidos durante meus estudos em front-end, com o objetivo de praticar HTML semântico, estilização com CSS/Sass e utilização do framework Bootstrap para criação de layouts responsivos.

O projeto foi desenvolvido exclusivamente em front-end, com foco em layout e estrutura.

## Funcionalidades

- Página inicial com banners promocionais
- Listagem de produtos
- Página de detalhes do produto
- Estrutura típica de e-commerce
- Layout responsivo com Bootstrap

## Tecnologias utilizadas

- HTML5
- CSS3
- Sass
- Bootstrap

## Como executar o projeto

Basta abrir o arquivo `index.html` em um navegador web.

Não é necessária instalação de dependências ou servidor local.

## Observações

Este projeto tem caráter educacional e foi desenvolvido com foco nos fundamentos do desenvolvimento front-end.
